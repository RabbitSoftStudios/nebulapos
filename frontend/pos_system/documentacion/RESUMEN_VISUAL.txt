## 🎓 REFERENCIAS RÁPIDAS

### Fórmula Clave
```
Si cliente pagó TOTAL_CON_IVA:
  
  SIN_IVA = TOTAL_CON_IVA / 1.13
  IVA = TOTAL_CON_IVA - SIN_IVA
  
Ejemplo: $48.00
  SIN_IVA = 48 / 1.13 = 42.48
  IVA = 48 - 42.48 = 5.52
  Verificación: 42.48 + 5.52 = 48.00 ✓
```

### JSON Correcto
```json
{
  "resumen": {
    "totalGravada": 48.00,           ← Lo que pagó
    "montoTotalOperacion": 42.48,    ← Sin IVA
    "totalPagar": 48.00,             ← Lo que pagó
    "totalIva": 5.52,                ← IVA extraído
    "tributos": [
      {
        "codigo": "20",
        "descripcion": "Impuesto al Valor Agregado 13%",
        "valor": 5.52
      }
    ]
  }
}
```
